## 課程交付要求

依組員提供的「期中資訊」截圖整理：

- 11 月 5 日（四）下午 5 點前，將團隊 GitHub 網址提交至課程 Discord 指定提交區。

## 協作方式

1. 使用各自的 GitHub 帳號接受協作邀請。
2. 在自己的工作分支修改檔案，完成後提交 commit，說明具體變更。
3. 透過 Pull Request 讓另一位組員檢查，再合併至主分支。
4. 各自實際完成並提交自己的工作；不代造其他成員的貢獻紀錄。
